📐 All Brainstormed Architecture & Feature Decisions (Quick Reference)

Use this reference table while coding from scratch so all 4 group members stay 100% aligned on database columns, color hex codes, validation rules, and QA targets.

1. Play Store Dark-Mode Theme Palette (MikeAndrew + Christian)

  • • App Canvas Background: #0B0F19 (Deep Obsidian)
  • • Elevated Card Surface: #111827 / #1E293B
  • • Primary Brand / Active Status: #10B981 (Neon Emerald)
  • • Secondary Accent / Machine Badge: #6366F1 (Electric Indigo)
  • • Warning / Expiring Soon (1–7d): #F59E0B (Amber)
  • • Danger / Expired (≤0d) / Primary Muscle: #F43F5E (Crimson)

2. Member Form & Safety Validation Rules (Christian + Broderick)

  • • Mandatory Fields: Full Name, Contact Number, Email, Emergency Contact Name, Emergency Contact Phone.
  • • Optional Fields: Birthdate and Home Address (speeds up registration to < 45 seconds while prioritizing emergency safety on the gym floor).
  • • Password Security: SHA-256 hashing via MessageDigest.getInstance("SHA-256").

3. Real-Time Device Clock & Renewal Logic (Jhan Vince + Christian)

  • • Java Clock Check: LocalDate.now() and ChronoUnit.DAYS.between(today, endDate).
  • • SQLite View Check: julianday(end_date) - julianday(date('now','localtime')).
  • • 1-Month Renewal Rule: If still active, newEnd = currentEnd.plusMonths(1); if already expired, newEnd = LocalDate.now().plusMonths(1).

4. Hybrid Offline/Online Exercise Visuals & Machines (All 4)

  • • 32 Exercises Seeded: 21 Commercial Gym Machines (⚙ Machine) + 11 Free-Weight/Bodyweight (✓ No Machine).
  • • User Toggle: [✓] Include Gym Machines checkbox + pill filters.
  • • 3-Tier Hybrid Media: Tier 1 loads local images/*.gif (offline); Tier 2 caches remote GIF URLs when on Wi-Fi; Tier 3 draws a 12 FPS Java2D anatomical muscle map + stick-figure animation.
